# Vizyon

Channel Foundry klasik bir YouTube web sitesi değildir.

Kullanıcı siteye video izlemek için değil,
videolar arasında saklanan hikâyeyi keşfetmek için gelir.

Web sitesi bir araştırma alanı gibi hissettirmelidir.

Kullanıcı;

karakterleri,

olayları,

ilişkileri,

videoları,

teorileri

keşfederek ilerler.

Studio ise bu dünyanın görünmeyen tarafıdır.

Kanal sahibi bütün içerikleri Studio üzerinden yönetir.

Web sitesi yalnızca sunum katmanıdır.

Studio üretir.

Web sitesi gösterir.

Projenin temel amacı teknoloji üretmek değil,
kaliteli bir kullanıcı deneyimi oluşturmaktır.
